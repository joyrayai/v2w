# Web UI 改版记录

更新时间：2026-06-22

## 背景

当前 V2W 已经从单一视频转写扩展到 Word、OKF、MCP、额外文件、企业审查、网盘任务等能力。功能增加后，首页工作台的视觉层级变弱，核心任务入口被预告和多个同级配置面板稀释。

## 优先改版方向

1. 首页工作台先服务“新建任务”，不要把 Roadmap 放在核心输入前。
2. 首屏优先展示链接输入、输出选择和开始任务。
3. 将“额外文件”“输出格式”“OKF 知识格式”合并为一个“输出设置”区域。
4. OKF 默认以开关和简短说明呈现，owner、version、tags 放入高级设置。
5. 任务列表保持在主流程下方，用于查看状态和下载 Word / OKF ZIP。
6. Web UI 逐步转为管理台：账号、模型配置、网盘授权、任务队列、用量、权限和 webhook。

## 推荐信息架构

- 新建任务
  - 来源：直链 / 网盘
  - 链接输入或目录选择
  - 输出设置：Word、Markdown、OKF、额外文件
  - 开始任务
- 任务队列
  - 状态
  - 下载
  - 用量
- 管理台
  - 账号与权限
  - 模型配置
  - 网盘授权
  - webhook 配置
  - 用量统计

## 第一阶段可执行改动

1. 从主工作台移走或折叠 `RoadmapNotice`。
2. 压缩顶部 `pageHeader`，把输入区提前。
3. 合并 `OutputFormatPanel`、`OkfPanel`、`ExtraDocs` 为“输出设置”。
4. 将 OKF 的详细字段改为可展开高级设置。
5. 调整移动端导航，减少顶部 tab 拥挤。
